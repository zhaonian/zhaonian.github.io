Privacy Policy for Juneau

Effective Date: September 2, 2026

Trademark Disclaimer: Juneau is an independent third-party mobile client developed for use with Google Jules. Juneau is not affiliated with, sponsored by, or endorsed by Google LLC. Jules and Google are trademarks of Google LLC.
Summary: Juneau operates entirely client-side on your iOS device. We do not operate developer tracking servers, intermediary proxy nodes, or telemetry services. Your API keys are encrypted locally using Apple iOS Keychain Services.

1. Information We Collect (Zero Tracking)

Juneau is designed with privacy-first architecture. We do not collect, store, log, or transmit any personal data, usage metrics, device identifiers, or analytics to developer-controlled servers.

2. API Key Credentials & Local Hardware Encryption

To use Juneau, you provide your personal Google Jules API Key generated at jules.google.com/settings/api. Your API key is:

  • Stored exclusively on your iOS device using Apple iOS Keychain Services (kSecClassGenericPassword), protected by hardware-level Secure Enclave encryption.
  • Never sent to any third-party server, proxy, or developer infrastructure.
  • Purged instantly from your device's Keychain whenever you tap "Disconnect API Key" in the app's Settings menu.

3. Direct API Communication

All network traffic—including fetching repository sources, task sessions, activity logs, implementation plans, and sending user prompts—is transmitted directly from your iOS device to Google's official endpoints (https://jules.googleapis.com) over secure, encrypted TLS/HTTPS protocols.

4. Data Minimization & GitHub Repositories

Juneau only processes repository metadata and task activity payload data returned directly by the official Google Jules API for the sole purpose of rendering the user interface on your mobile screen. Juneau does not store your code repository files on external servers.

5. Children's Privacy

Juneau is a developer tool designed for software engineers and does not knowingly collect any data from children under the age of 13.

6. Changes to This Privacy Policy

We may update our Privacy Policy periodically. Any updates will be posted directly to this page with an updated effective date.
